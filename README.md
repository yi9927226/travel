## 檔案結構

刻意保持**扁平**：所有 HTML 與 `index.html` 放在同一層，連結一律使用同層相對路徑。

```
travel/
├── index.html          ← 唯一入口，連向全部 24 份
├── README.md
├── 福岡逐日行程-*.html          行程 3 份
├── 福岡博多北九州景點清單-*.html  景點 1 份
├── 福岡住宿候選-*.html          住宿 19 份
└── fukuoka-stay-shortlist.html  最早的英文 shortlist
```

不分子資料夾的原因：頁面之間靠 index 導覽，分層對讀者沒有幫助，卻會讓已分享出去的 GitHub Pages 網址全部失效。

## 新增頁面時

1. 把新的 `.html` 放在 repo 根目錄（沿用 `主題-YYYY-MM-DD-NN.html` 命名）。
2. 在 `index.html` 對應區塊加一列 `<a class="row" href="檔名.html">`，並更新 header 的份數 chip 與頁尾統計。
3. commit、push，GitHub Pages 會自動重新部署。
